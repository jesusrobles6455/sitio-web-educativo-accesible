# Sitio Web Educativo Accesible

Proyecto desarrollado con el marco de trabajo Scrum (4 Sprints).

## Descripción
Plataforma educativa accesible que cumple con WCAG 2.1 nivel AA.
Incluye lecturas adaptables, videos con subtítulos, quizzes interactivos, descarga PDF offline, guías docentes, panel de administración y módulo de soporte.

## Sprints
- Sprint 1: Estructura base + Lecturas + Videos + Buscador
- Sprint 2: Quizzes interactivos accesibles
- Sprint 3: Descarga PDF offline + Guías didácticas
- Sprint 4: Panel de administración + Soporte y reportes

## Tecnologías
HTML5, CSS3, JavaScript, ARIA, WebVTT, PDF/UA
